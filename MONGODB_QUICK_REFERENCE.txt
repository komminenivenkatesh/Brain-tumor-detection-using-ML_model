❌ TROUBLESHOOTING
════════════════════════════════════════════════════════════════════

Problem: "Connection refused" or "Connection timed out"
├─ Cause: MongoDB not running
└─ Fix: 
   • Local: Run `mongod` or start MongoDB service
   • Docker: `docker start brain-tumor-mongodb`
   • Atlas: Check internet connection and firewall

Problem: "Authentication failed"
├─ Cause: Wrong username/password
└─ Fix:
   • Verify credentials in connection string
   • Test in MongoDB Compass first
   • Reset password if forgotten

Problem: "IP not whitelisted" (Atlas only)
├─ Cause: Your IP not in Network Access list
└─ Fix:
   • Go to Security → Network Access
   • Add your IP or use 0.0.0.0/0 for testing
   • Check home vs. work IP

Problem: Port already in use
├─ Cause: Another MongoDB instance running
└─ Fix:
   • Find process: netstat -ano | findstr :27017
   • Kill it: taskkill /PID [PID] /F
   • Use different port: mongodb://localhost:27018
