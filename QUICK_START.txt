🔧 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────
  Port in use?
  $ netstat -ano | findstr :8000
  $ taskkill /PID [PID] /F

  Missing packages?
  $ cd web_app/backend && pip install -r requirements.txt
  $ cd web_app/frontend && npm install

  TensorFlow issues?
  $ pip install tensorflow --upgrade
